# AI Chatbot Service

Intelligent chatbot powered by RAG (Retrieval-Augmented Generation) for answering questions about your portfolio.

## Features

- **RAG Implementation**: Retrieves context from knowledge base
- **pgvector Integration**: Fast similarity search for relevant information
- **Conversation Memory**: Maintains context across chat sessions
- **Real-time Responses**: Low-latency question answering
- **Customizable**: Easy to update knowledge base

## Architecture

## Technology Stack

- **Base Image**: jasonacox/chatbot
- **Vector Database**: PostgreSQL with pgvector extension
- **Embeddings**: sentence-transformers (all-MiniLM-L6-v2)
- **RAG Framework**: LangChain
- **Language**: Python 3.11

### Skills Database Schema

```sql
-- Table for storing embeddings
CREATE TABLE knowledge_base (
    id SERIAL PRIMARY KEY,
    category VARCHAR(50),           -- 'skill', 'project', 'experience'
    title VARCHAR(255),
    description TEXT,
    embedding vector(384),          -- Embedding vector (384 dimensions)
    tags TEXT[],
    metadata JSONB,
    created_at TIMESTAMP DEFAULT NOW()
);

-- Index for fast similarity search
CREATE INDEX ON knowledge_base 
USING ivfflat (embedding vector_cosine_ops)
WITH (lists = 100);

-- Conversation history
CREATE TABLE conversations (
    id SERIAL PRIMARY KEY,
    session_id VARCHAR(255),
    user_message TEXT,
    bot_response TEXT,
    context_used TEXT[],
    timestamp TIMESTAMP DEFAULT NOW()
);
```

## RAG Pipeline

### 1. Embedding Generation
```python
# Convert text to vector representation
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('all-MiniLM-L6-v2')
embedding = model.encode("What is your Kubernetes experience?")
# Result: [0.123, -0.456, 0.789, ...] (384 dimensions)
```

### 2. Similarity Search
```sql
-- Find top 5 most relevant knowledge entries
SELECT 
    title,
    description,
    1 - (embedding <=> $1::vector) as similarity
FROM knowledge_base
ORDER BY embedding <=> $1::vector
LIMIT 5;
```

### 3. Context Assembly
Combine retrieved knowledge into a prompt:

```
Context:
- Managed Kubernetes clusters for 3+ years at Justdial
- Experience with EKS, kubectl, and Helm
- Certified Kubernetes Administrator (CKA) prep

Question: What is your Kubernetes experience?

Answer: [Generated by LLM]
```

## API Endpoints

### POST /chat
Send a message to the chatbot

```bash
curl -X POST http://chatbot:8080/chat \
  -H "Content-Type: application/json" \
  -d '{
    "message": "What is your experience with AWS?",
    "sessionId": "user-123"
  }'
```

Response:

## Development

### Local Setup

```bash
# Install dependencies
pip install -r requirements.txt

# Set environment variables
export DATABASE_URL=postgresql://user:pass@localhost:5432/portfolio

# Run migrations
python scripts/init_db.py

# Seed knowledge base
python scripts/seed_knowledge.py

# Start service
python -m chatbot.main
```

### Docker

```bash
# Build image
docker build -t portfolio-chatbot .

# Run container
docker run -p 8080:8080 \
  -e DATABASE_URL=postgresql://user:pass@postgres:5432/portfolio \
  portfolio-chatbot
```

## Updating Knowledge Base

To add new information:

1. Edit JSON files in `data/` directory
2. Run seeding script:
```bash
python scripts/seed_knowledge.py --force-update
```

3. Restart service (Kubernetes will auto-reload)

## Performance Tuning

- **Embedding Model**: Larger models = better quality, slower speed
- **Context Length**: More context = better answers, higher latency
- **Temperature**: Lower (0.3) = deterministic, Higher (0.9) = creative
- **pgvector Index**: Tune `lists` parameter based on dataset size
